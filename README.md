# Aetherfold Idle 2

FFXI-style idle yard. Jobs, trusts, and field combat in West Ronfaure, Ghelsba, King Ranperre's Tomb, Ranguemont Pass, and Beaucedine Glacier.

```bash
npm install
npm run dev
```

The dev server listens on port 8080. Auth and the database stay off. The live yard save is not in this repo.
